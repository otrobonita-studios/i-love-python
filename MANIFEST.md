# I ❤️ PY — Manifest

> A demo that proves it loves Python, not just says it.
> **Otrobonita AI Labs — Jesper Karlsson**

Every requirement in `spec.md` maps to a real file and a real check. Nothing here
is simulated: the telemetry panel shows actual tool output, the review panel reads
real git diffs from this repo, and the load test hits this very app.

## The five modes

| Mode | What it does | Backed by | Verified by |
|---|---|---|---|
| 💗 **Landing** | The heart, the promise | `art/heart.py` (parametric curve, pure math) | `pytest tests/unit/test_heart.py` |
| 📊 **Quality telemetry** | Real `ruff`, `mypy --strict`, `pytest --cov`, `radon`, `bandit`, `pip-audit` runs | `panel/telemetry.py` | `python -m panel.telemetry` (prints the same report the panel shows) |
| 🗣️ **Review** | Purist / Skeptic / Pragmatist verdicts on real commit diffs | `review/personas.py`, `review/store.py` | `pytest tests/unit/test_personas.py` |
| 🕰️ **Git discipline** | A guided "ask git" session debugging a real bug in this repo's history, plus a good-vs-bad commit timeline | `git_discipline/console.py`, `git_discipline/timeline.py` | `pytest tests/unit/test_timeline.py` |
| 🏋️ **Load test** | k6 script *generated from a Python dataclass*, run (k6 or Python VU simulator), NDJSON parsed in Python into a live chart | `loadtest/spec.py`, `loadtest/generate.py`, `loadtest/report.py`, `loadtest/simulator.py` | `pytest tests/integration/test_full_loop.py` |

## The pure-Python rule

Hand-authored source is Python. Non-Python artifacts exist **only** when they are
generated by Python and say so in their header:

| Artifact | Generated by | Rule |
|---|---|---|
| `generated/k6/load_test.js` | `loadtest/generate.py` | starts with `// GENERATED` |
| `.github/workflows/ci.yml` | `scripts/ci_yaml.py` | starts with `# GENERATED` |
| `.git/hooks/pre-commit` | `scripts/install_hooks.py` | starts with `# GENERATED` |

Enforced by `python scripts/lang_audit.py` (fails CI and the pre-commit hook on
any hand-authored non-Python source file).

## Quality stack

| Tool | Invocation | Where the result is visible |
|---|---|---|
| ruff format | `ruff format --check` | Quality panel, CI |
| ruff lint | `ruff check` | Quality panel, CI |
| mypy | `mypy --strict` | Quality panel, CI |
| pytest + coverage | `pytest --cov` (fail under 70%) | Quality panel (per-file table), CI |
| radon | `radon cc` (complexity letter counts) | Quality panel |
| bandit | `bandit -r` | Quality panel, CI |
| pip-audit | `pip-audit` (offline → reported as such, never faked) | Quality panel, CI |
| lang audit | `scripts/lang_audit.py` | Quality panel, CI, pre-commit |

## Run it

```bash
python -m venv .venv && .venv\Scripts\activate        # (Windows)
pip install -e .[dev]
python app.py                                          # → http://localhost:8321
```

## Honesty policy

- Tool missing / offline → the panel says exactly that, with a gray "unavailable".
- Mutation testing (`mutmut`) is available (`python -m mutmut run`) but *optional* —
  it is slow and never gates the demo.
- The load panel labels its data source: `k6` (real), `simulator` (real HTTP from
  Python), or `fixture` (deterministic, offline). Never unlabelled.
