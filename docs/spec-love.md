## 1. Landing mark

### 1.1 Lockup

- Wordmark from `art/logo.py` (serif I, PY). Hide the Glaser heart glyph.
- Overlay the **parametric** heart from `art/heart.py` — the same curve the
  rest of the repo tests:
  `x = 16 sin³ t`, `y = 13 cos t − 5 cos 2t − 2 cos 3t − cos 4t`.
- The overlay sits snug to the **right of the I**, point above PY, not
  overlapping the letters.
- Nudge the overlay **10 CSS pixels to the right** of a mathematically
  centered placement (`left: calc(<center>% + 10px)` or equivalent).

### 1.2 ViewBox (load-bearing)

The curve is **signed** (x ∈ [−16, 16], y spans negative and positive). The
SVG `viewBox` must contain the whole path.

- Project with a y-flip (SVG y grows down):
  `X = originX + x · scale`, `Y = originY − y · scale`.
- Choose `originX`, `originY` so every sampled point lands **inside**
  `[0, width] × [0, height]`. Padding ~8 units.
- **Rejected:** `overflow: visible` as a substitute for a correct viewBox.
  That was the misalignment: the box framed only the right lobe.

Test: sample n≥64 points; after projection, min X/Y ≥ 0 and max X/Y ≤
width/height.

### 1.3 Draw animation

1. Stroke draws via `stroke-dashoffset` 0 → length, ~1.35s, ease-out.
2. Fill fades in as the stroke completes, ~0.55s.
3. Then the heartbeat (1.4).
4. Clicking the heart **replays** from stroke zero (draw → fill → 8 beats).

CSS/SVG animation is allowed only if it is **emitted by Python** (inline from
`art/render.py` or a GENERATED-headed artifact). No hand-authored `.css` /
`.js` files.

### 1.4 Heartbeat

- Period 1.35s. Dual-thump keyframes (scale 1 → 1.045 → 1 → 1.03 → 1).
- **Exactly 8 iterations, then stop** (`animation-iteration-count: 8`,
  `forwards`, resting scale 1).
- Replay restarts the 8.
- `prefers-reduced-motion: reduce`: no draw, no beat; heart is filled at rest.

### 1.5 Caption and palette

Under the mark, one line, spec.md §1:

> Rendered by the code you're about to inspect.

| Token   | Value     | Role        |
|---------|-----------|-------------|
| Paper   | `#F4EEE4` | background  |
| Surface | `#FBF7F0` | cards       |
| Ink     | `#161412` | text        |
| Heart   | `#EE1C25` | the mark    |

Typography: a real serif for the wordmark and letter (Newsreader or a system

1. I guess everyone has been there. A potential love affair across the room, seemingly impossible to reach, or even to get a short talk with. Is that feeling the first sign of something true, or just the pull of what won't come close?

2. I tried. But the outfit was hard to read, and that made the whole thing harder still. Or was it only playing hard to catch? This species had simply renamed everything I knew. No const, no npm install, no package.json. Instead: def, venv, __init__.py, and whitespace that means something. Not by intent, but by indentation.

3. And it lived on the server, while I lived in the browser. A complicated wall to tear down.

4. Years passed. I stayed in the browser. I'm a local guy after all.

5. That backend language kept surfacing anyway — always somewhere adjacent, never quite mine.

6. Then the models arrived. The agents, the orchestration frameworks, the whole new layer. Python-native, all of it.

7. And suddenly there was a beautiful way in — to the inner soul of that particular accent. Because that's what it turned out to be: an accent. Different names for things I already knew. Not a different way of thinking. Just a different way of saying it. Probably one of the most uncomplicated tools for a purpose it was never designed for: simulating human thinking, reasoning, learning, and problem-solving. I just had to treat it — as a human.

8. As a real partner. Understand the philosophy and you won't be afraid anymore: readability as an explicit design value, a shallow on-ramp, one obvious way to do it. And those same traits — plus a knack for wrapping fast C code — turned out to be exactly what scientific computing needed: NumPy, SciPy, and all the ML frameworks that followed.

9. So I dropped the excuses and asked it out properly.

10. What you'll find in this repo is, most people would say, anything but romantic. It's the opposite of a honeymoon. It's testing the relationship before it ruins the investment you're about to make — looking under the hood, finding the limits of a Python-only stack, and checking how good the tools really are when you ask them to prove it.

## 3. `import this`

The reused love letter is the one that already shipped with the language.

### 3.1 Control

```
┌─────────────────────────────┐   ┌──────────────┐
│  >>> import this            │   │ ▶  Execute   │
└─────────────────────────────┘   └──────────────┘
```

- Code well on the left. **Execute is outside the well**, same row, right.
- Never inside the chip. Never stacked under it at any breakpoint.
- Play icon is a filled triangle, not a chevron or `>`. After Execute the
  label becomes **Hide**. Hide removes the Zen card (the whole well) and
  the button becomes **Execute** again.
- Row does not wrap. Code well `flex: 1; min-width: 0`. Button does not shrink.

### 3.2 Output

On Execute, print the Zen of Python **below** the row, then continue the letter.

**Do not hand-author the English.** Decode CPython's own module:

```python
import codecs
import this as this_mod

zen = codecs.decode(this_mod.s, "rot_13")
```

Tests: the decoded string starts with `The Zen of Python, by Tim Peters` and
contains `Readability counts.` and `Namespaces are one honking great idea`.

Idle caption:

> One line. The rest of the philosophy is in the output.

## 4. Tool glossary

Quality cards currently show a command, a badge, and raw stdout. That is not
an explanation. A curious reader who does not live in Python must still
understand the page.

### 4.1 Per-card contract

Each of the eight quality results shows, in this order:

1. Name, kind label (formatter / linter / type checker / tests / complexity /
   security / dependencies / house rule), command.
2. **What it is** — the `what` sentence below.
3. **This run.** — the real parsed output, including failures.
4. A link to official docs (`href` below). `target=_blank` for external URLs.

N/A still means unavailable. Never a fake pass. The pytest failure and the
lang-audit failure stay failed.

### 4.2 Copy and URLs (canonical)

Store in `explain/glossary.py` (or equivalent). `panel/render.py` looks up by
tool name. Tests assert every telemetry tool has a glossary row with a URL.

| name | kind | what | why | href |
|---|---|---|---|---|
| ruff format | formatter | A Python code formatter, from Astral. It picks the spaces, quotes, and line breaks so nobody has to. The equivalent of one house style for the whole repo. | We run it as a check, never a rewrite: if a file isn't already formatted, the snapshot fails. | https://docs.astral.sh/ruff/formatter/ |
| ruff lint | linter | A linter: it reads the code without running it and flags unused imports, likely bugs, and outdated syntax. Think of a proofreader that never gets tired. | Catches the mistakes a formatter cannot — the ones that are still valid Python, just wrong. | https://docs.astral.sh/ruff/linter/ |
| mypy --strict | type checker | A static type checker. Python is dynamic; mypy reads the type annotations and proves — before the program runs — that names, returns, and optionals actually match. | --strict is the hardest setting: no untyped functions, no implicit optionals. The whole codebase is annotated to survive it. | https://mypy.readthedocs.io/en/stable/command_line.html#cmdoption-mypy-strict |
| pytest --cov | tests | pytest is the test runner. The --cov plugin (pytest-cov) then counts which lines those tests actually executed. Green tests with untested code still leave you blind. | This repo fails the run if coverage drops under 70% — and a single failed test fails the gate even when coverage is high. | https://docs.pytest.org/en/stable/ |
| radon cc | complexity | Cyclomatic complexity: how many independent paths a function has. A is a straight line. E is a maze. | The gate allows A, B, and a few C's. D and E would fail the build. | https://radon.readthedocs.io/en/latest/intro.html#cyclomatic-complexity |
| bandit -r | security | A security linter from PyCQA. It hunts for patterns that become exploits: SQL injection, shelling out with user input, weak cryptography, eval(). | It does not prove the code is safe. It catches the obvious mistakes before a reviewer has to. | https://bandit.readthedocs.io/en/latest/ |
| pip-audit | dependencies | A PyPA tool that checks installed packages against the known-vulnerability database. Perfect formatting can still ship a rotten dependency. | Needs network. If this check is missing, we show N/A — never a fake pass. | https://github.com/pypa/pip-audit |
| lang-audit | house rule | Ours. A small Python script that walks the tree and fails if it finds hand-authored JavaScript, shell, or other non-Python source. | Generated files need a GENERATED header, or they live under generated/. Love, in this studio, is one language. | repo `scripts/lang_audit.py` |

### 11.2 Essay (canonical)

Python will draw you a whole interface without leaving the language. That is a real gift: one runtime, one voice, the browser as a guest. What it does not have is React’s ocean of libraries, or the ease of a component you install and forget.

So you choose Python on purpose. When the UI is light. When a conversation does most of the work — a chat, a letter, a panel that tells the truth — and the page is a room for that, not an application. This heart is that kind of UI.

You’ve seen I ❤ NY your whole life: a serif I, a fat red heart, two letters underneath. In 1977 a New York designer named Milton Glaser sketched it with a crayon in the back of a cab. The doodle outlived the man. Almost nobody can name him. Almost everybody can draw the mark.

This one rhymes with it — I ❤ PY — but it is not a tracing and it is not clip-art. It is sampled from a closed parametric curve, the same function the tests lock down. Drag t. Watch the point walk the outline. Math you can feel — in the language that drew it. Python on a string!
